🔐 एडमिन लॉगिन

GitHub Personal Access Token डालें ताकि data.json को अपडेट किया जा सके। टोकन केवल आपके ब्राउज़र में सेव होगा।

यह टोकन code में कहीं hard-code नहीं किया गया है।
टोकन कैसे बनाएँ?
  1. github.com → Settings → Developer settings
  2. Personal access tokens → Tokens (classic)
  3. Generate new token → scope में repo चुनें
  4. टोकन कॉपी करके यहाँ पेस्ट करें
